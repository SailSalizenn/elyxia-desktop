# Elyxia desktop — releases

This repository holds only the Windows installers for the Elyxia desktop app,
so the app can update itself. There's no source code here.

Download the latest **Elyxia-Setup-x.y.z.exe** from [Releases](../../releases/latest).

The installer isn't code-signed: the first time, Windows may say
"Windows protected your PC". Choose **More info → Run anyway**.
